# 🍊 Swiggy Sales Analysis Dashboard – Excel

## 📌 Project Overview
An interactive sales analysis dashboard built using Microsoft Excel to track Swiggy's sales performance, customer ratings, order volume, and regional trends.

## 🎯 Key KPIs
- **Total Sales:** 53.0M
- **Average Rating:** 4.34
- **Average Order Value (AOV):** ₹268.51
- **Rating Count:** 5,591,574
- **Total Orders:** 197,430

## 📊 Dashboard Features
- Monthly Sales Trend
- Daily Sales Trend
- Weekly Sales Trend
- Sales by Food Type (Veg vs Non-Veg)
- State-wise Sales Analysis
- Top 5 States by Sales
- Quarterly Sales, Ratings & Orders
- Interactive Month, State, and City slicers

## 🛠️ Tools & Skills
- Microsoft Excel
- PivotTables & PivotCharts
- Interactive Slicers
- KPI Cards
- Data Visualization
- Business Intelligence & Sales Analysis

## 💡 Business Insights
- Veg food contributes approximately 64% of total sales.
- The average customer rating is 4.34.
- Saturday records the highest daily sales among the displayed weekdays.
- Karnataka leads the Top 5 States by Sales in this dashboard.

## 🎯 Project Objective
To transform sales data into an interactive dashboard that helps stakeholders monitor performance, identify regional sales patterns, and understand customer preferences.
